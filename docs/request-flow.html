      读完演示，还需要区分的三件事
      

        
分配编号 ≠ 计算 KV
BlockManager 只分配使用权。Q/K/V 在各层投影后产生；K/V 写入池，Q 用于本次 attention，不作为历史 KV 缓存。

        
采样一个 token ≠ 已缓存它
Prefill 就会采样第一个输出。下一次 decode 才把这个输出送入模型、写入它的 KV，再采样下一个。最后一个输出无需再输入模型，请求就可结束。

        
块用完 ≠ 自动扩容
需要新块且无空闲块时，scheduler 会抢占请求，归还引用并等待重新 prefill；这里没有 CPU swap。单个请求超过整个池容量也无法靠追加编号解决。
